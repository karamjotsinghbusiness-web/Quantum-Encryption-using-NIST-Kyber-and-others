# Changelog

All notable changes to CipherShield are documented here.

## [0.1.0] — 2026-09-25

Initial research-lab release.

### Included

- RSA-OAEP, P-256 ECDH, and ML-KEM-768 hybrid encryption with AES-256-GCM.
- RSA-PSS, ECDSA P-256, and ML-DSA-65 signatures.
- Functional round-trip and tamper-detection tests.
- Versioned benchmark JSON with runtime and dependency metadata.
- Architecture, methodology, security, contribution, citation, and guided-demo documentation.
- Continuous integration, CodeQL analysis, dependency updates, and structured contribution templates.

### Scope

CipherShield 0.1.0 is educational software. It is not an antivirus, production
cryptosystem, FIPS-validated module, or peer-reviewed research result.
